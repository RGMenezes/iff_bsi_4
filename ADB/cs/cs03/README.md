# Atividade de Administração de Banco de Dados (ABD)
## Exercícios de Join, Desafios e Consultas Aninhadas

Esta **pasta** contém a lista de exercícios propostos para a disciplina de ABD.

---

### Enunciados das Questões

1. Mostrar os nomes dos clientes que já fizeram compras na papelaria.
2. Mostrar a quantidade de vendas realizadas por vendedor em ordem decrescente.
3. Altere a consulta anterior para mostrar apenas a linha do “melhor” vendedor.
4. Exibir uma lista de todos os produtos com os respectivos fabricantes.
5. Mostrar os nomes dos clientes que fizeram compras no ano de 2011.
6. Listar dados das vendas feitas com o respectivo nome do vendedor. Mesmo os vendedores que nunca venderam nada devem ser mostrados.
7. Exibir lista de TODOS os vendedores com a cidade onde moram.
8. Exibir a lista de cidades com quantitativo de clientes. O objetivo é saber qual cidade tem mais clientes.
9. Exibir a descrição e id do produto mais barato;
10. Exibir descrições e id’s dos produtos que têm valor maior que a média de valores dos produtos em ordem decrescente de valor;

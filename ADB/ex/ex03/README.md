# Desafios Join

- Desafio 1: exibir a lista de vendedores com os produtos que já
venderam. Em ordem decrescente de nome do vendedor.
- Desafio 2: evoluir a consulta anterior para mostrar a quantidade
de produtos já vendidos por cada vendedor em ordem
decrescente de quantidade de produtos. Será necessário
agrupar.
- Desafio 3: Ainda no desafio 1 e se precisássemos mostrar todos
os produtos até mesmo os que nunca foram vendidos?
- Desafio 4: Exibir uma lista dos fabricantes que já forneceram para
cada cliente. A lista deve mostrar o nome do cliente e
descricao do fabricante.
